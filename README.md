# Full-Stack E-Commerce Web Application (Next.js & Django)

This is a full-stack e-commerce web application featuring a **Next.js** frontend and a **Django / Django REST Framework** backend, powered by a **PostgreSQL** database.

## Tech Stack

* **Frontend:** Next.js, React, Tailwind CSS
* **Backend:** Django, Django REST Framework (DRF)
* **Database:** PostgreSQL
* **Other Tools:** Gunicorn, Whitenoise, Python-Dotenv, Psycopg2, JWT Authentication, CORS Headers
